# Memory index

Read this file at the start of every session. One line per memory, detail in the memory file, never here.

**When to save:** the moment the user states a fact about themselves, their business, their voice, or a
decision that should still hold next session. Not at the end of the day. Never save what the repo
already records (`onboarding/intake.md`, `wiki/`, this file's rules).

**One fact per file:** `memory/<kebab-slug>.md`
```
---
name: <kebab-slug>
type: user | feedback | project | reference
---
<the fact, one short paragraph. For feedback add a "Why:" line and a "How to apply:" line.>
```
Fix a memory that turns out wrong. Delete one that is dead. Your memories are yours: `.gitignore`
keeps them out of any repo you push.
