## Shooting notes

- **PNG, and crop tight.** Show the button being pressed, not the whole desktop.
- **1600px wide is plenty.** Keep each file under about 500 KB so a clone stays light.
- **Windows or Mac, either is fine** for these six. The screens are close enough that one set works,
  and the platform-specific detail is covered in the recorded walkthrough.
- **Check the frame before you save:** no email address, no client names, no other tabs, no file paths
  with your own name in them.
- **Screenshots are not the lesson.** The full recorded walkthrough lives in the classroom. These stills
  are for the person who just wants to check they clicked the right thing.
